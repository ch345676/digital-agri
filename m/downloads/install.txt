惠农智慧农场 1.0.2

安装文件：huinong-farm-1.0.2.apk
适用系统：Android 8.0 及以上。

已安装 1.0.0 或 1.0.1：直接下载本版本并覆盖安装，保留已有记录。不要先卸载旧版。
本次修复“网页无法打开 / net::ERR_HTTP_RESPONSE_CODE_FAILURE”：旧包使用了 Windows 反斜杠资源路径，导致 Android 找不到本地首页。新版统一为 Android 可读取的路径，并增加原始 APK 路径检查和原生首页预检。
保留网页内核兼容脚本、启动失败重试、页面进程恢复和兼容绘制模式。
如果新版本仍打不开，请使用“复制诊断信息”，或展开页面上的“查看诊断信息”并反馈内容。

下载 APK 后点击安装，按手机提示允许当前下载来源安装应用。
首次打开可选择游客预览，或使用管理员 admin / admin123 体验完整功能。

新增内容：五地块档案、农事任务分派与照片验收、预警处置闭环、农场时间轴、三个自动场景演示、可调参数的产量情景试算、照片浏览与拖拽面板、页面与操作动效。

页面、图片和卫星地图已内置，断网可用；天气和外部设备控制链接需要网络。
账号和演示记录保存在本机，网页与 APK 的数据各自独立。本版本未连接真实农机设备。
