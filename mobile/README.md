# 惠农移动端 · 蓝白卡片主题

独立移动端源码，对应原站 `/digital-agri/m/`。由工作区历史移动端源码迁入，保留原有账号和 `agri-mobile-state-v1` 数据结构。

## 启动与构建

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 3210
npm run build
```

构建产物为 `dist/`，使用相对资源路径，可部署到 `/m/`。部署时只替换移动端目录，桌面端构建独立。

## 设计与动效

参考用户提供的仪表盘图片：冰蓝背景、白色大圆角卡片、蓝色概览卡、黄绿色强调、深色胶囊按钮。保留预警红橙风险标识。

- 8 个业务路由：概览、灌溉、预警、识别、巡检、协作、预测、施药。
- 登录/注册与个人面板使用同一套视觉风格。
- 页面淡入淡出、导航高亮滑动、按钮按压/触点反馈、图表描线、数字递增。
- 预警列表与详情双向过渡，处理后列表重排，趋势选择与防治建议展开。
- 灌溉分区面板和阀门状态反馈；巡检自动/手动控制区高度过渡。
- 识别结果、咨询面板、聊天消息沿用并统一原有动效；施药四步向导、记录和回执切换过渡。
- 系统减少动态效果时取消位移与装饰动画；装饰视频在离屏、后台或减少动态效果时暂停。
- 底部导航适配安全区，修复动效弹层水平居中与叠放。

`src/editorial.css` 管理视觉令牌与主题；共享组件位于 `src/components/`。图片和视频复用现有农业素材。

## 验证

启动本地服务器后运行：

```sh
node scripts/verify-editorial.mjs
```

覆盖 320/390/768 像素、8 条业务路由、预警处理持久化、趋势切换、个人弹层定位、灌溉完成、巡检模式切换、施药全流程与回执保存、离屏视频暂停、减少动态效果与运行时错误检查。截图与 JSON 报告位于 `qa/editorial/`。

项目仍为原有静态演示应用；本次工作更新界面与过渡效果，没有连接新的农业硬件或业务服务。
