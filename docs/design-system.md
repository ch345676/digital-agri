# 惠农界面规范

本轮以农场总览、任务管理、土壤报告为三种代表布局，建立同一套工作台规范。全站沿用现有业务和演示数据。

## 视觉归属

- `workbench.css` 统一颜色、字号、边界、控件及响应式页面构图。
- `widgets.css` 只保留地图概览、读数仪表与提示组件的结构。
- `theme.css` 保留旧页面的基础布局；已删除旧深色主题对 Tailwind 业务控件的全局着色。
- 停止加载 `glass.css`、`fresh.css`、`refinement.css`。后续禁止重新导入旧主题覆盖新规范。
- `motion-system.css` 负责过渡和状态变化，不另设静态主题。

## 规则

1. 暖白工作区与白色信息面，深森林绿用于主操作、选中导航和今日作业。异常色用于异常状态。
2. 标题约 30 px，正文 14–15 px，操作及辅助信息 12–13 px；图片来源、单位与次级图例可以更小。
3. 页面只有重点区域、普通区域和嵌入信息三种层级。列表通过对齐与分隔线组织；不为每一行增加卡片、图标底座与多个标签。
4. 总览先呈现作业指标，再呈现可点选的田块地图与生长简报，预警、今日任务及统计依次展开。
5. 任务清单在宽屏对齐内容、负责人、计划时间、状态和操作；窄屏按内容、元信息、操作三个顺序排列。
6. 土壤图谱与指标共享外框、标题层级和留白。指标选择器同时展示八项读数，选择后关联参考区间和元素通道。生成图谱仍明确标注为示意。
7. 设备照片采用统一 16:10 预览，主体铺满；保留原图来源。继续使用无人入镜的田间设备素材。
8. 主操作保留短促反馈；筛选、导航、展开与完成状态以连贯过渡表达变化。移除普遍的图标弹跳与指针微光监听。

## 验收

先关闭动画检查静态构图；再验证任务创建和状态、筛选/看板、土壤字段与 N/P/K/OM 联动、弹窗关闭、打印与导出、手机导航，以及关闭动画/减少动态效果。

主要检查命令：

```text
node node_modules/typescript/bin/tsc -b
node node_modules/vite/bin/vite.js build
node scripts/verify-huinong.mjs
node scripts/verify-insights.mjs
node scripts/verify-soil-finish.mjs
node scripts/verify-motion-system.mjs
```

自动浏览器截屏不稳定时可设置 `SKIP_SCREENSHOTS=1` 跳过测试中的截屏步骤；布局与业务断言仍执行，视觉截图需单独复查。
