# 平台交互动效

本次为桌面平台及其响应式布局统一动效。沿用现有农业配图、数据与业务逻辑，无新增动画依赖。

## 覆盖范围

| 模块 | 交互表现 |
| --- | --- |
| 全站导航、总览 | 有方向的页面切换、滚动分批入场、真实阅读位置细线、数值插值 |
| 任务、预警、采摘、设备 | 筛选选中背景滑动、卡片退出和重排、状态变化高亮 |
| 作物 | 双向高度展开、内部信息错峰出现、新记录入场 |
| 农场地图 | 详情面板宽度/高度展开与收起、图层淡出、地块描边与切换 |
| 智能巡检 | 小车巡航、状态切换、进度变化、项目照片弹窗 |
| 土壤报告 | 指标与地块联动过渡、连续刻度、保留根系与元素粒子演示 |
| 数据复盘 | 日期联动解读、采样日历点选、图表过渡与读数变化 |
| 经营分析 | 统计范围、种植结构与观察联动、保留水肥流向粒子 |
| 物资、团队、设置 | 表格状态反馈、成员/公告入场、表单聚焦、开关位移、保存提示 |
| 通知、弹窗、展示模式 | 打开与关闭过渡、关闭过程不可交互、弹窗内容保留至退出完成 |
| 操作按钮 | 主操作有点击反馈；次级控件通过状态与选中变化反馈，支持键盘操作 |

## 接入与边界

- `MotionRuntime` 使用共享观察器管理入场、集合重排、筛选背景和读数更新。稳定的 `data-motion-item` 标记集合项；`data-motion-key` 只标记需要联动更新的局部内容；`data-status` 标记业务状态。
- 选项组使用 `.segmented`、`.field-tabs`、`.map-field-picker` 或 `data-motion-tabs`，当前选项须有 `aria-pressed="true"` 或 `active`。
- `ButtonMotion` 采用事件委托，不延迟实际点击；临时波纹有超时清理。大图查看按钮不覆盖扩散特效。
- `Expand`、`usePresence` 与地图详情负责双向展开/关闭；关闭时保留内容但设置 `inert`，避免隐藏控件继续接受焦点。
- 一般反馈约 180–300 ms，页面和入场约 320–430 ms。跟随指针的效果不旋转卡片或文字。滚动进度是真实位置，导出进度沿用实际事件，未增加假加载。
- 顶部动画开关、系统减少动态效果设置、后台暂停、离屏场景暂停及打印样式均适用。重复点击取消被替代的动画；全局关闭会清理观察器和临时节点。

## 验证

构建后启动 Vite preview，默认 `http://127.0.0.1:5184/`。脚本支持 `TEST_BASE`；Windows 中使用 Chrome 无头模式及禁用窗口遮挡节流的参数，以检查真实中间帧。

`verify-huinong.mjs` 和 `verify-scenes.mjs` 支持 `SKIP_SCREENSHOTS=1`，可在已完成视觉专项检查后，仅运行布局和业务回归；不跳过打印或导出验证。

```text
node scripts/verify-motion.mjs
node scripts/verify-motion-system.mjs
node scripts/verify-huinong.mjs
node scripts/verify-insights.mjs
node scripts/verify-scenes.mjs
node scripts/verify-soil-finish.mjs
```

动效专项覆盖快速导航、指针/键盘、筛选重排、弹窗退出、地图与图层关闭、数值联动、全局停用、减少动态效果和 320/390/768 像素窄屏。原有功能脚本覆盖 14 个页面及任务、预警、导出、采摘、阀门等业务闭环。
