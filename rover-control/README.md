# 惠农巡检小车移动控制台

访问 `/digital-agri/rover-control/`。页面是独立的静态移动网页，使用项目已有的农田底图、小车照片和巡检视角样片；地图的巡检路线与原移动端共用坐标。

底部导航切换五个独立视图：路线、操控、镜头、相册、喷洒。操控页提供自动巡航与暂停、手动虚拟摇杆、方向键、速度档位、返航和紧急停止。摇杆支持任意方向和按幅度调速，松开即停。镜头页提供照明、云台转向，并可选择真实作物问题参考照片，模拟在小车当前位置拍照。

相册显示三条预置演示记录和在本机创建的模拟拍照记录，记录包含参考照片、来源、巡检地块和示意坐标；路线图同步显示位置标记。新增记录保存在浏览器 `localStorage`，不会上传，清除网站数据后会丢失。照片均是真实摄影作品，但不是本项目小车拍摄的照片，也不能据此确诊作物问题。来源和许可见 [PHOTO-SOURCES.md](PHOTO-SOURCES.md)。

喷洒页可选择地块、作业范围并保存模拟计划到浏览器。喷洒模块尚未安装，页面明确显示离线，实际启动按钮保持禁用，不会发送喷洒指令。移动端巡检页和桌面端巡检页均有入口。支持添加到手机主屏幕。

页面内所有状态均为浏览器本地仿真。没有实时 GPS、摄像头流、后端服务或实车指令。接入实车前需明确通信协议，并实现身份认证、连接状态、遥测反馈、命令确认、失联停车、地理围栏与硬件急停联锁。网页中的急停仅作用于仿真。

从仓库根目录运行 `node scripts/verify-rover-control.mjs` 可验证关键交互和常见手机宽度。发布时将整个 `rover-control/` 目录复制到 `gh-pages` 分支根目录；`main` 分支保留源码。
